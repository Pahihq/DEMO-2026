# На SRV-L


Установка Prometheus
``` bash
dnf install golang-github-prometheus -y
systemctl enable prometheus --now
```

Настройка Node Exporter (srv-l)
Создаем пользователя:
``` bash
useradd -rs /bin/false nodeusr
```
Устанавливаем exporter:
``` bash
dnf install prometheus-node_exporter -y
```
Запускаем сервис:
``` bash
systemctl enable node_exporter --now
```

```bash
nano /etc/prometheus/prometheus.yml
# Добовляем в конец файла
```
``` yaml
  - job_name: "HQ-SRV"
    static_configs:
      - targets: ['192.168.100.2:9100']
  - job_name: "BR-SRV"
    static_configs:
      - targets: ['192.168.250.2:9100']
```
Перезапускаем:
``` bash
systemctl restart prometheus
```
Установка Grafana
``` bash
dnf install grafana -y
systemctl enable grafana-server --now
```

Открываем веб‑интерфейс:
http://`<IP_srv-l>`:3000
Первый вход:
login: admin\
password: admin
После входа сменить пароль:
admin / P@ssw0rd

**Подключение Prometheus к Grafana**
Путь:
Home → Connections → Data Sources → Add data source
Выбрать **Prometheus**.
Указать адрес:
    http://localhost:9090
Нажать:
Save & Test

Импорт Dashboard
Рекомендуемый dashboard:
Node Exporter Full
**ID: 1860**
Revision: **27**
Импорт:
Home → Dashboards → New → Import
Загрузить JSON файл и выбрать источник **Prometheus**.
