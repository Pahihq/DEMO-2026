# На RTR-L
Настройте межсетевой экран на маршрутизаторах RTR-L на сеть в сторону ISP
```bash
nft add chain ip nat input { type nat hook input priority 0 \; }
nft add rule ip nat input udp dport 53 accept  
nft add rule ip nat input tcp dport 80 accept  
nft add rule ip nat input tcp dport 443 accept  
nft add rule ip nat input tcp dport 123 accept  
nft add rule ip nat input ct state { established, related } accept  
nft add rule ip nat input ip protocol gre accept  
nft add rule ip nat input ip protocol icmp accept  
nft add rule ip nat input ip protocol ospf accept  
nft add rule ip nat input udp dport 500 accept  
nft add rule ip nat input ip saddr 192.168.100.0/27 accept  
nft add rule ip nat input ip saddr 192.168.200.0/28 accept  
nft add rule ip nat input ip saddr 192.168.0.0/29 accept  
nft add rule ip nat input ip version 4 drop
```
